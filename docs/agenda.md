# M365 Copilot Workshop — David James Estate Agents

**Audience:** ~45 attendees
**Format:** 1-hour "art of the possible" showcase across 5 topics, followed by breakout group work, closing with a live showcase of shortlisted ideas.
**Facilitator note:** You (the trainer) own the Idea Board app. Attendees discuss and pitch ideas verbally in their groups; you capture and tag them centrally during report-backs — attendees do not use the app directly.

## Suggested running order (adjust timings to your day length)

| Time | Segment | Detail |
|---|---|---|
| 0:00 – 0:05 | Welcome & framing | Introduce the day, link explicitly to David James's business goals (capture these live — see "Business goals capture" below). |
| 0:05 – 1:05 | **Art of the possible (1 hour, all 5 topics)** | Live demo-led tour. Suggested split: ~12 min per topic. |
| | 1. Copilot in the web | |
| | 2. Copilot within M365 apps | |
| | 3. Agents built by standard Copilot | |
| | 4. Advanced agents & workflows (Copilot Studio) | |
| | 5. Application development & reporting (GitHub Copilot) | |
| 1:05 – 1:15 | Break / form breakout groups | Mix departments where possible (sales, lettings, admin, marketing, management) so ideas cross-pollinate. |
| 1:15 – 2:15 | **Breakout group working session** | Groups discuss: "Where could Copilot save us time or help us hit [business goal]?" Use the Idea Capture Worksheet (`idea-capture-worksheet.md`) as a scaffold — paper or verbal, facilitator's choice. |
| 2:15 – 2:30 | Break | Facilitator pre-loads report-back order. |
| 2:30 – 3:15 | **Group report-backs** | Each group presents their top 2–3 ideas (3–5 min each). Facilitator captures every idea live in the Idea Board app, tagging **Idea only** or **Shortlisted**. |
| 3:15 – 3:30 | Shortlist confirmation | Quick group discussion/vote to confirm which shortlisted ideas get a demo scenario built before the showcase. |
| 3:30 – 4:15 | **Demo scenario build time** | Groups (or facilitator-supported pairs) build a lightweight test/demo for their shortlisted idea (e.g. a Copilot Studio agent, a Copilot prompt flow, a GitHub Copilot-assisted script). |
| 4:15 – 4:45 | **Final showcase** | Each shortlisted group presents & demos their idea (5–7 min each, depending on count). Use "Print Showcase Cards" from the app as presentation prompts. |
| 4:45 – 5:00 | Wrap-up & next steps | Summarise themes, confirm follow-up owners, export the full idea board (JSON/CSV) as a leave-behind artifact. |

> Total: ~5 hours including breaks. Trim the demo scenario build / showcase segments if running a half-day, or split breakouts and showcase into a second session.

## Business goals capture

Since business goals will be gathered live during the workshop, build in 5 minutes at the start to ask leadership/attendees to state 3–5 priorities (e.g. lead conversion speed, client communication, compliance/document turnaround, listing-to-market time, staff productivity). Write these on a flipchart/shared screen and refer back to them explicitly during report-backs so groups anchor ideas to real goals.
