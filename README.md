# M365 Copilot Workshop Toolkit — David James Estate Agents

Materials and a lightweight idea-capture tool for delivering the M365 Copilot workshop (1-hour art of the possible across 5 topics, breakout ideation, shortlisting, demo build, and final showcase).

## Contents

- `docs/agenda.md` — suggested running order for the full workshop day.
- `docs/facilitator-guide.md` — how to run breakouts and use the Idea Board app as facilitator.
- `docs/idea-capture-worksheet.md` — optional paper backup for groups, mirrors the app's fields.
- `docs/demo-showcase-guide.md` — running the closing showcase where shortlisted ideas are demoed.
- `app/` — the Idea Board web app (open `app/index.html` in any browser, no install or internet required).

## Idea Board app

A single-page app for the facilitator to capture ideas raised by breakout groups during report-backs, tag each as **Idea only** or **Shortlisted** (moves into a demo/test scenario), and manage the day:

- All data saved locally in the browser (no backend, works offline).
- Filter ideas by topic or status.
- Export/import JSON to merge ideas captured across multiple devices/rooms.
- Export CSV for easy sharing with leadership.
- **Print Showcase Cards** — generates a printable page per shortlisted idea for the final showcase.

To use: open `app/index.html` directly in a browser (double-click the file, or `open app/index.html` on macOS).
